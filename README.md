# 杂交稻制种受托与授权

协调杂交稻品种授权、制种受托、田块排程和批次交付。

## 领域范围

系统涉及种业企业、制种受托人、县域管理人员、独立检验人员。当前领域资料记录以下业务事实：

- 制种区域覆盖多个县并承接大量水稻品种
- 行业发布制种价格指数和受托人分级制度
- 品种评价同时关注产量、品质、抗逆与适应性

后续实现需要围绕这些边界组织服务：

- 品种授权版本
- 受托人分级
- 田块排他排程
- 生产事件证据
- 灾害影响结算

`contracts/domain.schema.json` 定义领域资料结构，`fixtures/domain.json` 提供不含真实身份信息的示例，`src/hybrid_rice_seed_trustee/context.py` 负责读取并检查这些资料。

## 开发命令

- 运行测试：`python3 -m unittest discover -s tests -v`
- 编译检查：`python3 -m compileall -q src`

上述命令只读取仓库内资料，不需要连接外部业务服务。
